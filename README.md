#Car Garage Billing System

A Java-based project for Managing a car garage billing system.

##Overview

This is my First Java Project. The car Garage Billing System allows a customer to:
- **Add Customer Details**:- Input details such as name, phone number, car model and car number
- **Choose a Service**:- After entering their details, the customer can select a service from available options such as (Wheel alignment, tyre replacement, Oil change etc)
- **Calculate Billing**:- Automatically compute the total amount due based on the selected service.
- **Print an Invoice**:- Once the service is selected, an invoice is generated and printed, displaying  the customer details, the selected services and the total billing amount.
- **Exit**:- An option to exit the system is provided after displaying all the choices.

  ##Key features:-
  - **User-friendly Interface**:- A simple, menu-driven approach guides the customerthrough the billing process.
  - **Service-based billing**:- The system calculates the final billing amount on the customer's service selection.
  - **Invoice generation**:- All relevant details ( customer information, service an dtotal cost) are compiled into a clear invoice.
